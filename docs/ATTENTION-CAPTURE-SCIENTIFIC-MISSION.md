# Attention Capture → Scientific Mission

## Purpose

This document defines the reusable qFoldIT Attention Capture layer as a distribution and human-compute mechanism for `INDUSTRIAL-CAMEO`.

The layer does not make narrative or entertainment IP authoritative over scientific evaluation. Scientific truth remains owned by the designated validator (for example OpenStructure for structural biology).

## Canonical conveyor

```text
Narrative context
  -> Original qFoldIT presentation or expressly licensed third-party presentation
  -> Quest object / interactive mesh
  -> Mission contract
  -> UAG / MCP compilation
  -> Runtime adapter
  -> Human spatial interaction
  -> Submission / event record
  -> CAMEO reconciliation
  -> Domain scientific validator
  -> Evidence / contribution record
  -> Enterprise deliverable
```

## Runtime-neutral design

A narrative layer is optional. The scientific mission remains fully executable with no entertainment IP dependency.

The minimum machine chain is:

```text
mission -> router -> compiler -> UAG -> runtime -> submission -> validation
```

The attention layer augments the chain:

```text
attention context -> quest framing -> human interaction -> submission
```

This makes the attention mechanism portable across UEFN, Unity, UNIGINE, Web and Standalone while preserving the same mission and validation semantics.

## Scientific authority boundary

- Narrative assets never define the target truth.
- Runtime physics never defines the authoritative scientific score.
- Player success never implies scientific validity.
- CAMEO routes the submission to the declared scientific validator.
- Scientific validators operate against protected references or other controlled ground truth.
- Reward policy is evaluated only after the scientific result and evidence record exist.

## Enterprise use cases

The same mechanism can frame missions for:

- protein / ligand design;
- RNA or peptide structural search;
- semiconductor topology and routing search;
- battery / materials geometry;
- catalyst and adsorption structures;
- industrial optimization and spatial configuration tasks.

The mission payload should contain machine-readable scientific semantics. Narrative copy and visual assets remain a presentation layer.

## Evidence posture

This repository currently documents the architecture. It does not claim measured retention uplift, millions of active scientific contributors, a universal Fair Use right, or a guaranteed enterprise return from the attention layer.

Those claims require controlled experiments, production mission telemetry, signed customer evidence and scientific outcome comparisons.
